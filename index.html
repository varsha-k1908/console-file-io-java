01 • INTRODUCTION

Understanding Java I/O

Input and output allow a Java program to communicate with users and external data sources.

↔

What is I/O?

Input means receiving data, while output means displaying or storing data produced by a program.

⌨

Console I/O

Data is entered through the keyboard and results are displayed in the console. The Scanner class is commonly used for input.

▤

File I/O

Data can be read from or written to files using classes such as FileReader and FileWriter.

CONSOLE I/O

Temporary interaction

Useful when a program needs information directly from a user or needs to show immediate results.

VS
FILE I/O

Persistent data

Useful when information needs to be stored and accessed again after the program ends.

02 • CONSOLE INPUT-OUTPUT

Reading and writing from the console

Java provides System.in for standard input and System.out for standard output.

Scanner class

Scanner is a simple way to read different types of data from the keyboard.

  • nextInt() — reads an integer
  • nextDouble() — reads a decimal number
  • next() — reads one word
  • nextLine() — reads a complete line
Tip: Always close the Scanner when you no longer need it.
ConsoleInput.java
import java.util.Scanner;

public class ConsoleInput {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = sc.nextLine();

        System.out.print("Enter your age: ");
        int age = sc.nextInt();

        System.out.println("Name: " + name);
        System.out.println("Age: " + age);

        sc.close();
    }
}

03 • READING FILES

Reading data from a file

File input allows a Java program to retrieve information stored in a text file.

CHARACTER STREAM

FileReader

Reads characters from a text file. It is suitable for basic character-by-character file reading.

FileReader reader = new FileReader("data.txt");
BUFFERED READING

BufferedReader

Reads text efficiently and provides readLine() for convenient line-by-line reading.

BufferedReader br = new BufferedReader(reader);
ReadFile.java
import java.io.*;

public class ReadFile {
    public static void main(String[] args) {
        try {
            FileReader fr = new FileReader("data.txt");
            BufferedReader br = new BufferedReader(fr);

            String line;
            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }

            br.close();
            fr.close();
        } catch (IOException e) {
            System.out.println("Error reading file.");
        }
    }
}

04 • WRITING FILES

Writing data to a file

File output lets a program save information so it can be used later.

CHARACTER STREAM

FileWriter

Writes character data to a file. It can create a new file or write to an existing file.

FileWriter writer = new FileWriter("output.txt");
BUFFERED WRITING

BufferedWriter

Buffers output and provides convenient methods such as newLine().

BufferedWriter bw = new BufferedWriter(writer);
WriteFile.java
import java.io.*;

public class WriteFile {
    public static void main(String[] args) {
        try {
            FileWriter fw = new FileWriter("output.txt");
            BufferedWriter bw = new BufferedWriter(fw);

            bw.write("Java File I/O");
            bw.newLine();
            bw.write("Writing data to a file.");

            bw.close();
            fw.close();

            System.out.println("Data written successfully.");
        } catch (IOException e) {
            System.out.println("Error writing file.");
        }
    }
}

06 • CONCLUSION

Choosing the right I/O approach

Console I/O is useful for direct interaction with users, while file I/O is useful when information needs to be stored and reused. Java provides simple classes such as Scanner, FileReader, BufferedReader, FileWriter, and BufferedWriter to handle these tasks.

KEY TAKEAWAY Input brings data into a program. Output sends or stores data from a program.
